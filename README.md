# Varun Vijay — Game-Inspired Engineering Portfolio

This is a static, responsive portfolio website built with plain HTML, CSS, and JavaScript.

## Files

- `index.html` — page structure and portfolio content
- `styles.css` — original battle-royale-inspired visual design
- `script.js` — project modals, skill loadouts, filters, XP progress, sounds, and animations
- `Varun_Vijay_Engineering_Portfolio.pdf` — downloadable PDF portfolio

## Open locally

Double-click `index.html`. An internet connection is only used to load the Google Fonts. The site still works without them.

## Publish free with GitHub Pages

1. Create a new public GitHub repository.
2. Upload all files from this folder to the repository root.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/root`, then save.
6. GitHub will provide a public website link.

## Publish free with Netlify

Drag this entire folder onto Netlify Drop. Netlify will immediately create a public link.

## Easy edits

Contact details and portfolio content are in `index.html`.

Project popup content and skill-loadout values are in `script.js`.

Visual colours and layout are in `styles.css` under `:root`.

## Design note

The interface uses an original battle-royale/game-lobby aesthetic. It does not include copied logos, characters, artwork, audio, or other proprietary game assets.
